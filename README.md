# موقع «إلهام» — بروتوكول الإضافة

أي طرف مخوّل (مساعد ذكاء اصطناعي، تطبيق، أو مطوّر) يمكنه إضافة تدوينة جديدة باتباع هذه الخطوات بالترتيب.

## البنية

```
ilham-site/
├── index.html          ← الصفحة (تُبنى تلقائياً من entries.json)
├── data/entries.json   ← مصدر البيانات الوحيد
├── build.py            ← يحقن entries.json داخل index.html
├── add_entry.py        ← إضافة + بناء + نشر بأمر واحد
├── manifest.json       ← PWA
├── sw.js               ← Service Worker
└── assets/             ← الخطوط، الأيقونات، الصور المصغرة
```

## خطوات إضافة تدوينة جديدة

### 1. سحب بيانات المقطع من يوتيوب
```bash
yt-dlp --write-auto-subs --sub-langs "ar-orig" --skip-download -o "yt_<ID>" "<URL>"
curl -s "https://www.youtube.com/oembed?url=<URL>&format=json"
```
- oembed يعطي العنوان واسم القناة (غالباً فيه اسم القائل).

### 2. الصورة المصغرة
```bash
curl -s -o assets/thumbs/<ID>.jpg "https://i.ytimg.com/vi/<ID>/mqdefault.jpg"
```

### 3. صياغة التدوينة
أضف كائناً جديداً في نهاية `data/entries.json` بنفس بنية التدوينات السابقة:

```json
{
  "id": "t<الرقم التالي>",
  "date": "<اليوم بالعربية> <التاريخ> — <الوقت> صباحاً/مساءً",
  "speaker": "<اسم القائل: الشيخ/د./المهندس/الأستاذ فلان>",
  "title": "<عنوان — مقولة بين شرطتين « — »>",
  "body": ["<فقرات بنص غني>"],
  "boxes": [{"type": "khulasa|fiqh", "label": "خلاصة|فقه", "text": "..."}],
  "source": "<الرابط الأصلي>",
  "category": "<تزكية النفس | الدعاء والأذكار | علوم القرآن>",
  "tags": ["<وسوم>، <اسم القائل ضمنها>"],
  "thumb": "assets/thumbs/<ID>.jpg"
}
```

**رموز النص الغني داخل body وboxes:**
- `﴿آية﴾` → أخضر عريض تلقائياً
- `«قول»` → أزرق عريض
- `((تحذير))` → أحمر عريض
- `[[مفهوم]]` → تظليل أصفر

**قواعد تحريرية:** إعادة صياغة فصيحة لا نسخ حرفي من الترجمة العامة؛ فقرة خلاصة دائماً؛ فقرة فقه عند الحاجة للتدقيق؛ اسم القائل وسيماً ضمن tags.

### 4. النشر
```bash
git pull origin main          # مهم: اسحب أولاً لتجنب التعارضات
python3 build.py
python3 add_entry.py <entry.json>   # أو عدّل entries.json يدوياً ثم:
git add -A && git commit -m "Add entry t<N>" && git push origin main
```

### 5. التحقق
انتظر دقيقة ثم: `curl -s https://zerouno2345seis-oss.github.io/ilham-site/ | grep "<جزء من العنوان>"`

## قواعد صارمة

1. **اسحب (pull) قبل كل دفع (push)** — أكثر من طرف يعمل على المستودع.
2. **لا تعدّل التدوينات القديمة** — أضف فقط، إلا بطلب صريح من مالك الموقع.
3. **لا تحذف** build.py أو sw.js أو manifest.json.
4. التكرار ممنوع: إن كان `source` موجوداً في entries.json فالمقطع مضاف من قبل.
5. أزل تشويش الترجمة الآلية (تكرار الكلمات، الهمزات الناقصة) وأعد الصياغة فصيحاً.
